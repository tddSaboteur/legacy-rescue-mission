# 🛠️ Пролетарская Кузница TDD (proletarian-tdd-forge)

> "Разработчики всех стран, застрявшие в легаси без бюджетов! Нам нечего терять, кроме своих костылей." — *Из Манифеста TDD-Диверсанта.*

Добро пожаловать на анонимный испытательный полигон инженерного сопротивления. Этот репозиторий — художественная реконструкция реального корпоративного ада, перенесенная в безопасный сеттинг космических кораблей для обхода NDA.

## 💣 Наша Цель
Показать на живых примерах, что каноны красивых книжек работают даже там, где теоретические тесты "в лоб" бессильны. Мы берем запущенные легаси-модули, изолируем внешнюю грязь (сеть, базы данных, сторонние библиотеки) через интерфейсы-шлюзы и закладываем TDD-мины замедленного действия, превращая хаос в расширяемый код без потери обратной совместимости.
## 🚩 Хроники Освобождения Труда (План вылазок):
* **[Коммит №1] Взятие в плен модуля camel-ftp со всеми грехами и 7-минутными падающими тестами.**
  Залита стартовая точка — оригинальный код компонента `camel-ftp` https://github.com/apache/camel/tree/camel-4.21.0/components/camel-ftp из недр Apache Camel.
  *Состояние пленного:* "Божественные классы" намертво сшиты с библиотекой JSch. Родные юнит-тесты протухли, а интеграционные тесты идут 7 минут и стабильно валятся от сетевых таймаутов. Код зафиксирован в своем худшем, первозданном виде.
  Код настолько жестко завязан на инфраструктуру монолита Camel, что при переносе в отдельный модуль контекст просто взрывается. Накатить тесты без шаманства невозможно
